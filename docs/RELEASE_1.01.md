# Dark Reader 1.0 — Обновление 1.01

Версия приложения остаётся 1.0.0, внутренний номер сборки увеличен. Файл для установки: **DarkReader-1.01-unsigned.ipa**.

- Сохранение в iCloud теперь выключено по умолчанию, в том числе после обновления со старой версии, которая включала его при выборе папки. До явного включения папка не создаётся и записи в iCloud нет. При отключении ранее созданные копии сохраняются.
- После включения «Сохранять в iCloud» создаётся папка Dark Reader. Если подпись разрешает собственный контейнер iCloud, место выбирается автоматически. Иначе необходимо один раз разрешить доступ через «Файлы», после чего он запоминается.
- Обработка выбранной папки начинается после закрытия «Файлов». Создание закладки доступа и подготовка контейнера перенесены в фон, чтобы не блокировать интерфейс при нажатии «Открыть».
- Поиск аудиокниг оформлен как поиск книг: карточка выбранного источника, единое поле поиска, одинаковые переключатели и строка выбора языка. Убраны отдельная синяя ссылка и лишний заголовок источника.
- При добавлении и редактировании OPDS-каталога выбирается «Книги» или «Аудиокниги». Старые каталоги остаются книжными. Пользовательские аудиокаталоги появляются в выборе источника аудиопоиска; поддерживаются открытые ссылки audio/* и ленты глав OPDS 1.x.
- Язык книг в настройках выбирается строками с флагами и отметкой выбора, как язык приложения: Русский / English / Все языки.

Диагностика установленной предыдущей версии по SSH подтвердила: у текущей подписи отсутствуют разрешённые контейнеры iCloud. Полностью автоматическое создание папки без системного выбора требует подходящей подписи с iCloud Documents; одно изменение кода не добавляет эти разрешения. Подпись и файлы установленного приложения не изменялись.

Сборка IPA выполняется без запуска симулятора и тестов по запросу владельца. Исправленный сценарий выбора папки требует проверки на устройстве после установки обновления.
