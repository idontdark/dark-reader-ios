# Dark Reader 1.0 — Своя библиотека

- Google Drive: вход через Google, сохранение и восстановление электронной библиотеки, настроек, прогресса и именованных закладок. Используется только скрытая область приложения (`drive.appdata`). Можно включить автоматическое сохранение, отключить аккаунт или удалить копию.
- iCloud Drive: системный выбор папки через «Файлы», автоматическое создание папки Dark Reader внутри выбранного места; исправлена обработка доступа к папке. Если подпись поддерживает собственный контейнер iCloud, он выбирается автоматически, иначе место нужно выбрать один раз.
- В каталоге книг — Флибуста и Project Gutenberg; в аудио — LibriVox и Internet Archive. Кнопки сразу открывают поиск выбранного источника.
- Скачанные книги отмечены «В библиотеке»; рядом есть кнопка «Читать» и подтверждение добавления. Убраны ссылки «Загрузки»; пауза и продолжение доступны в строке книги. Устранено растягивание строк результатов при изменении прогресса.
- В библиотеке появилась полка «Загруженные книги». Исправлено общее избранное из рекомендаций и каталогов, добавлен отдельный список «Хочу прочитать» для рекомендаций.
- В читалке можно создавать, называть, переименовывать и удалять закладки. Добавлено избранное в верхней панели.
- Поле прямой ссылки оформлено в цветах приложения, пример ссылки серый.
- Процент прочтения включён по умолчанию; в настройках можно выбрать текущую страницу.

Скачивайте **DarkReader-1.0.0-unsigned.ipa** из Assets и подпишите перед установкой. При подписании сохраните идентификатор приложения **com.ipadark.reader** для входа Google.

Сборка выпускается без запуска симулятора и тестов по запросу владельца. Авторизация и операции с личным Google Drive/iCloud требуют проверки на подписанном приложении и устройстве. Google Cloud должен разрешать Drive API и область drive.appdata; статус In production сам по себе не подтверждает проверку бренда Google или работоспособность API.

В резервные копии входят электронные книги, а не локальные аудиофайлы. Запуск фонового сохранения зависит от iOS. Серии аудиокниг пока недоступны: подходящий сервис ещё не подключён.
