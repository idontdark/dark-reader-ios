# Dark Reader: подсказки и тексты (RU / EN)

## Принципы интерфейса

- Подсказка должна объяснять **действие**, а не описывать внутренние технологии. Короткая фраза предпочтительнее модального предупреждения.
- Не показывайте выдуманный прогресс. При известном размере показывайте проценты, иначе только индикатор.
- Не путайте «сохранено на устройстве» и «отправлено в iCloud Drive».
- Никогда не отображайте внутренние технические ошибки сервера пользователю.
- Английский интерфейс не должен скрывать русские книги: язык содержимого выбирается отдельно.
- Не повторяйте «Нажмите, чтобы скопировать» около каждого кошелька. Значок копирования и одно подтверждение достаточны.
- Поддерживайте Dynamic Type, VoiceOver и устойчивую вёрстку на маленьком iPhone.
- При отмене поиска сразу сбрасывайте спиннер, возвращайте кнопку «Найти книги» и отбрасывайте устаревшие ответы.

## Первый запуск

Язык, книги или аудиокниги, жанры, необязательные любимые авторы, начало чтения. Каждый шаг пропускается. Фото авторов не показываем. Каталог рекомендованных книг должен использовать реальные названия и обложки источника.

## Аудиокниги

Вкладка «Аудиокниги» содержит переключатель LibriVox / Internet Archive, поиск, обложки, главы и плеер. Указание интернет-ограничений только при медленном запросе или недоступности. Таймер сна, скорость и скачивание текущей главы доступны из плеера.

## Импорт

Поддерживаем EPUB, FB2, обычный MOBI без DRM и ZIP с книгой внутри. Данные FB2/MOBI локально преобразуются в EPUB перед открытием Readium. Ссылка должна быть HTTPS, но не обязана заканчиваться расширением, если формат определяется из ответа или сигнатуры.

## GitHub и QA

Сборка запускается из `main`, создаёт `DarkReader-0.6.0-unsigned.ipa` и проверяет `Payload/DarkReader.app`. В Releases загружается именно IPA. Проверяйте оба аудиоисточника на реальном iPhone, переключение источников, импорт EPUB/FB2/MOBI/ZIP и полноэкранную вёрстку до публичного релиза.
