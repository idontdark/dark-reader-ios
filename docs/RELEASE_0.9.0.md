# Dark Reader 0.9.0 — Новый дизайн

Переработаны первый запуск, библиотека, каталог, карточки книг и плеер по предоставленному референсу: объёмная книга и наушники, фиолетовые градиенты, компактные карточки, переключатели и нижняя навигация.

В читалке по умолчанию показывается процент прочтения. В настройках и меню «Aa» добавлен пункт **«Прогресс чтения»**: **«Процент прочтения» / «Текущая страница»**. Показатель обновляется по событиям Readium; выбор сохраняется. В EPUB используется рассчитанная позиционная нумерация, которая может отличаться от печатного издания.

Сохранены исправления 0.8.0: реальная перемотка, импорт аудио, очередь до трёх загрузок с resume data, OPDS, языковые подборки и кэш обложек. Прямые ссылки электронных книг также направлены в общую очередь.

Скачивайте **DarkReader-0.9.0-unsigned.ipa** из Assets. Для установки IPA нужна подпись.

Ограничения:
- Google Drive отложен: OAuth Client ID владельцем пока не настроен.
- Новые русскоязычные сайты не подключены без подтверждённого API и разрешённого стороннего воспроизведения. Наличие «Богатого папы» не гарантировано.
- На физическом iPhone/iPad проверки не выполнены. Фоновые ограничения iOS и управление с реального экрана блокировки требуют проверки на устройстве.
- В разделе серий отображаются реальные данные OPDS, когда источник их предоставляет; отсутствие данных обозначается явно.
- Содержимое карточек и обложки берутся из библиотеки и каталогов, поэтому зависят от книги.
