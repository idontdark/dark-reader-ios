# Техническое задание: полная переработка источников книг и аудиокниг

## 1. Основная задача

Полностью переработать систему поиска, получения и скачивания электронных книг и аудиокниг в существующем iOS-приложении.

**Основная концепция: один поиск по всем включённым источникам без ручного выбора сайта.**

Для каждого источника использовать наиболее подходящий способ интеграции: официальный API, OPDS, HTML-парсер, штатные ссылки на файлы или встроенный браузер.

Не ограничиваться OPDS. Большинство сайтов не предоставляет его, поэтому необходимо реализовать полноценную систему адаптеров.

Существующий дизайн приложения сохранить.

## 2. Изменения интерфейса

### 2.1. Настройки

Полностью удалить из настроек раздел:

**«Каталоги / Ваши OPDS библиотеки»**

Убрать связанные с ним элементы:
- Добавление OPDS-каталога.
- Редактирование URL и названия.
- Список пользовательских OPDS-библиотек.
- Управление отдельными OPDS-каталогами.

При этом OPDS разрешается использовать внутри адаптеров, если он действительно работает. Просто пользователь больше не должен видеть или настраивать его вручную.

Существующие данные пользовательских OPDS-каталогов не удалять без необходимости. При миграции предусмотреть безопасное сохранение данных.

Вместо старого раздела создать **«Источники»** с двумя подразделами:

- Источники книг.
- Источники аудиокниг.

В каждом подразделе отображать список поддерживаемых сервисов.

Для каждого сервиса:

- Название.
- Домен.
- Переключатель включения/выключения.
- Кнопка «Проверить».
- Результат последней проверки.
- Краткое описание возможностей: поиск, чтение, скачивание, прослушивание.

Проверка должна учитывать не только открытие главной страницы, но и возможность выполнить поиск и получить содержимое карточки.

Под результатом проверки разместить подсказку:

> **Некоторые сервисы могут не отвечать при проверке, но при этом оставаться рабочими. Это может быть связано с региональными ограничениями или особенностями подключения. Рекомендуем повторить проверку с включённым VPN.**

Сервис не должен автоматически отключаться после неудачной проверки.

### 2.2. Поиск

**Полностью убрать выбор источника из поиска книг и аудиокниг.**

Поведение:

1. Пользователь открывает существующий поиск.
2. Вводит название, автора или другое ключевое слово.
3. Приложение автоматически обращается ко всем включённым источникам соответствующего типа.
4. Результаты постепенно отображаются в общем списке.
5. Повторяющиеся книги объединяются.

Если открыт раздел книг, поиск выполняется по включённым книжным источникам.

Если открыт раздел аудиокниг, поиск выполняется по включённым аудиоисточникам.

Не создавать отдельную вкладку специально для поиска аудиокниг.

Не показывать выпадающий список сайтов, переключатель источников или обязательный выбор библиотеки перед поиском.

Если один сайт не отвечает, остальные должны продолжать работать.

### 2.3. Вкладка «Библиотека»

Полностью убрать отдельные элементы и переходы на следующие внешние библиотеки:

- Флибуста.
- Project Gutenberg.
- LibriVox.
- Internet Archive.
- Книги в ухе.
- Аудиокниги клуб.

**Важно:** удалить именно их отображение во вкладке «Библиотека», а не соответствующие адаптеры поиска.

Эти сервисы могут оставаться среди доступных источников в настройках.

Во вкладке «Библиотека» оставить пользовательское содержимое: добавленные книги, загруженные аудиокниги, историю чтения, прогресс прослушивания и другие существующие функции.

### 4.3. Особые требования

**Akniga.org**

Изучить структуру карточки, список глав и штатный плеер. Проверить возможность использования доступных аудиопотоков во внутреннем проигрывателе.

**ASBook.ru**

**LibriVox**

Получать языки, исполнителей, главы, обложки и ссылки на аудиофайлы/RSS.

Остальные аудиоисточники исследовать аналогично, отдельно фиксируя подтверждённые возможности.

## 5. Логика общего поиска

Поиск должен работать параллельно по всем включённым источникам.

### Алгоритм

1. Пользователь вводит запрос.
2. Приложение определяет тип: книга или аудиокнига.
3. Получает список включённых источников этого типа.
4. Выполняет запросы с ограничением параллелизма.
5. Показывает результаты сразу после поступления.
6. Объединяет дубликаты.
7. Подгружает остальные результаты без блокировки интерфейса.

Не ждать завершения всех запросов, прежде чем показать первую найденную книгу.

Предусмотреть тайм-ауты, отмену старого поиска при новом запросе и ограничение частоты обращений.

### Объединение дубликатов

Для электронных книг использовать ISBN, название, автора, язык и издание.

Для аудиокниг дополнительно учитывать исполнителя, год записи и длительность.

**Разные озвучки одной книги не объединять в одну запись без возможности выбрать исполнителя.**

Если одна книга доступна на нескольких сайтах, показывать единую карточку с вариантами получения.

Предпочитать надёжные, проверенные источники. Не отправлять весь трафик одному сайту.

### Фильтрация по языку

Учитывать выбранный язык приложения и библиотеки.

При русском языке приоритетно показывать русскоязычные книги и аудиокниги, исключая англоязычные результаты из обычной русскоязычной выдачи, если пользователь не изменил соответствующий фильтр.

Язык определять по метаданным произведения, а не только по домену источника.

## 6. Карточка книги и аудиокниги

### Электронная книга

Показывать название, автора, обложку, описание, язык, жанр и доступные форматы.

При нажатии «Скачать» выбрать подходящий источник автоматически либо предоставить варианты источника и формата в карточке, если их несколько.

Выбор источника **в карточке допустим**, но в общем поиске его быть не должно.

### Аудиокнига

Показывать название, автора, исполнителя, обложку, длительность, главы и описание.

Действия:

- Слушать.
- Скачать, если поддерживается.
- Добавить в библиотеку.

Если доступно несколько озвучек, пользователь должен выбирать их в карточке книги.

## 7. Аудиоплеер

Обязательно обеспечить полноценное воспроизведение поддерживаемых аудиоформатов.

Требования:

- Воспроизведение и пауза.
- Перемотка по времени.
- Переключение глав.
- Регулировка скорости.
- Продолжение с последней позиции.
- Фоновое воспроизведение.
- Управление с экрана блокировки.
- Поддержка гарнитуры.
- Отображение информации через Now Playing.
- Офлайн-воспроизведение скачанных глав.
- Восстановление прогресса после перезапуска.

Не допускать ситуации, при которой пользователь выбирает главу, но проигрыватель не запускается.

Если источник не предоставляет воспроизводимый поток, не отображать нерабочую кнопку.

## 8. Скачивание

Создать общий DownloadManager для книг и аудиокниг.

Поддержать:

- Несколько одновременных загрузок.
- Очередь.
- Прогресс в процентах.
- Отмену.
- Повторную загрузку.
- Возобновление после обрыва, если сервер поддерживает.
- Проверку файлов.
- Автоматический импорт.
- Распаковку архивов.
- Восстановление очереди после перезапуска приложения, где это возможно.

Для аудиокниг сохранять порядок глав и сведения об исполнителе.

Все загрузки должны проверяться на целостность и допустимый формат. Не считать HTML-страницу или ошибку сайта успешным скачиванием.

## 10. Проверка сервисов

Кнопка «Проверить» должна выполнять диагностический запрос к конкретному источнику.

Этапы проверки:

1. Проверка доступности домена и HTTPS.
2. Проверка возможности открыть каталог.
3. Тестирование поиска.
4. Проверка карточки книги.
5. Проверка доступности поддерживаемого действия: скачивания или воспроизведения.

Не выполнять полную загрузку большой книги ради простой проверки сервиса.

Отображать результаты:

- Работает.
- Частично доступен.
- Не удалось проверить.

Состояние «Не удалось проверить» не должно означать, что сервис гарантированно не работает.

Подсказку о VPN показывать под результатом и внизу раздела источников.

Не отключать сервис автоматически после ошибки.

## 11. Настройки источников

Все переключатели должны сохраняться между запусками приложения.

Предусмотреть:

- Включение и отключение отдельного сервиса.
- Проверку конкретного сервиса.
- Проверку всех включённых сервисов.
- Дату и результат последней проверки.
- Краткое описание поддерживаемых возможностей.

Стабильно проверенные источники могут быть включены по умолчанию.

Экспериментальные источники, которые ещё не прошли тестирование, не должны автоматически участвовать в поиске.

Не показывать пользователю фиктивные результаты проверки.

## 12. Надёжность и безопасность

- Использовать HTTPS, если источник его поддерживает.
- Проверять перенаправления и типы файлов.
- Не передавать учётные данные одного сервиса другому.
- Не хранить пароли и токены в открытом виде.
- Ограничить размеры загрузок и архивов.
- Предотвращать опасную распаковку ZIP.
- Кэшировать метаданные и обложки.
- Учитывать региональные ограничения и сетевые ошибки.
- Не обходить CAPTCHA, DRM и платный доступ.
- Использовать штатные способы получения доступных пользователю файлов.
- Соблюдать ограничения и условия использования сторонних сервисов.

Наличие книги на стороннем сайте само по себе не означает наличие разрешения на её распространение. Автоматическую загрузку реализовывать только там, где она разрешена.

## 13. Тестирование

**Это обязательная часть работы, а не дополнительное пожелание.**

Для каждого источника проверить минимум пять разных произведений.

### Электронные книги

Проверить:

- Поиск.
- Карточку.
- Обложку.
- Метаданные.
- Доступные форматы.
- Штатное скачивание.
- Импорт в читалку.
- Открытие и чтение.

### Аудиокниги

Проверить:

- Поиск по названию.
- Поиск по автору.
- Поиск по исполнителю.
- Карточку и обложку.
- Список глав.
- Воспроизведение первой, средней и последней главы.
- Перемотку.
- Сохранение позиции.
- Скачивание, если поддерживается.
- Воспроизведение после перезапуска.

Тестировать как популярные, так и редкие произведения. Для фактических загрузок использовать материалы с разрешённым распространением.

Дополнительно провести тест общего поиска с несколькими одновременно включёнными сервисами, включая ситуацию, когда часть сайтов недоступна.
