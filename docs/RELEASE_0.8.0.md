# Dark Reader 0.8.0 — Новая глава

Предварительная версия. Скачивайте **DarkReader-0.8.0-unsigned.ipa** из Assets. IPA требует подписи для установки.

Изменения:
- Убрана повторная подсказка выбора языка; подборки используют издания на выбранном языке.
- Кэш обложек в памяти и на диске; запросы одной обложки объединяются.
- Персонализация учитывает выбранные книги, жанры, библиотеку и события чтения/прослушивания.
- Плеер проверяет доступные диапазоны перемотки; позиция обновляется после завершения seek. Добавлена скорость 1.75×.
- Сохраняемая очередь загрузок электронных книг, до трёх одновременно, пауза, отмена, повтор. Возобновление зависит от resume data сервера; иначе задача загружается заново.
- HTTP/HTTPS OPDS, относительные ссылки, OpenSearch, MIME FictionBook. Ссылки покупки не выдаются за бесплатное скачивание.
- Выбор и отключение аудиоисточников, фильтр Русский / English / Все; скрытая подмена LibriVox на другой источник убрана.
- Импорт MP3/M4A/M4B и ZIP, объединение файлов, метаданные, встроенные главы M4B, изменение названия, автора, обложки и порядка глав.
- Баннер «Время слушать», фильтры аудиобиблиотеки.

Ограничения:
- Google Drive не подключён: владелец пока не настроил OAuth Client ID. Автоматических копий аудиофайлов нет.
- Новые русскоязычные поставщики не подключены без подтверждённого API и разрешения на стороннее воспроизведение. LibriVox и Internet Archive остаются дополнительными источниками классики. «Богатый папа» не гарантирован.
- Проверки CI и сетевых запросов доступны в Actions, артефакт DarkReader-0.8.0-QA. Не все сетевые источники доступны из каждого региона.
- На физическом iPhone/iPad проверки пока не выполнены. Фоновый звук, управление с экрана блокировки и реальные пользовательские M4B требуют проверки на устройстве.
- Прямой импорт аудио ограничен 2 ГБ; большие ZIP/аудиофайлы могут требовать дополнительного свободного места.
- Точная фильтрация языка возможна только при достоверных метаданных провайдера.
- Для OPDS без поиска OpenSearch используется совместимый параметр поиска существующей настройки.
