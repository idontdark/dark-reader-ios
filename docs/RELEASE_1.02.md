# Dark Reader 1.0 — Обновление 1.02

- Кнопка скачивания всей аудиокниги на странице книги, прогресс по главам и отмена.
- Скачивание не запускает плеер. При повторной попытке сохранённые главы пропускаются. Доступ без интернета после полного скачивания.
- Единые поля поиска книг и аудиокниг, компактные карточки и действия в библиотеке.
- Скелетоны загрузки каталога, состояния ошибок и повторная попытка.
- Расширена локализация RU/EN, включая резервные копии и навигацию.
- Переработано подключение папки резервных копий: проверка записи, чтения и сохранения копии до включения. iCloud по умолчанию выключен. При отсутствии iCloud entitlements у подписи требуется ручной выбор папки в Files.

Версия приложения 1.0.0, сборка 12. Файл 1.02. IPA не подписан.

Сборка выполняется для устройства без запуска симулятора. Скачивание и выбор папки iCloud требуют проверки на физическом iPhone после установки; успешная компиляция не подтверждает работу сервисов на конкретном устройстве. Загрузка аудио продолжается при закрытии страницы внутри приложения, но не гарантируется после выгрузки приложения системой.

Макеты объединённой библиотеки в это обновление не включены.
