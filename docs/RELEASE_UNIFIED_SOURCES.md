# Dark Reader — unified sources preview

- A single progressive search across enabled book or audiobook sources.
- Source settings with independent switches, diagnostics and last-check results.
- Legacy custom OPDS settings are removed on migration; books, bookmarks and progress remain.
- Recommendations use declared genres, language, publication dates and recorded popularity. Reading and listening interests are independent.
- Persistent audio download queue, shared transfer limit, validated imports and ordinary website download fallback.
- Additional PDF, text, HTML, RTF and legacy DOC imports. Fixed-layout PDF and system DOC previews have different controls from EPUB.
- Russian and English localization for the new source screens.

Experimental sites remain disabled by default. Availability depends on the source and region; failed checks do not disable a source. Native asset checks are not proof of audible playback or real-device lock-screen/headset behavior. See the source audit report for confirmed and unverified capabilities.

Unsigned IPA: sign with your usual signing tool before installing. The marketing version remains 1.0.0; the installation filename remains dark-signer [v1.1].ipa.

Validation: generic iPhone Release compilation and 77 CLI checks passed. Live metadata audit matched 20 results in each of 10 genres. Website-only or partly available audio sources retain browser fallback; Aknigi24 remains experimental and disabled by default. Real iPhone playback, lock-screen/headset controls and archive downloads still require device verification.
